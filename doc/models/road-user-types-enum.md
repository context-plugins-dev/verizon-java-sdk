
# Road User Types Enum

The road user types:

- Vehicle: Vehicles with a metal box. Example: Car, Truck, Bus, etc.
- VulnerableRoadUser: Road users without protective housing. Example: Pedestrian, Cyclist, Motorcyclist, etc.
